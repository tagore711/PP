# Raw VCF Data

The raw 1000 Genomes VCF files (`ALL.chr*.shapeit2_integrated_snvindels_v2a_27022019.GRCh38.phased.vcf.gz`) are excluded from this repository because each chromosome file exceeds GitHub's 100 MB file size limit (total dataset is ~12.5 GB).

### Data Download
To run the analysis scripts from scratch, place the 1000 Genomes GRCh38 phased VCF files for chromosomes 1–22 in this directory:
- Expected format: `ALL.chr{chrom}.shapeit2_integrated_snvindels_v2a_27022019.GRCh38.phased.vcf.gz`
- Source: [1000 Genomes Project (GRCh38 Release)](http://ftp.1000genomes.ebi.ac.uk/vol1/ftp/data_collections/1000_genomes_project/release/20190312_biallelic_SNV_and_INDEL/)
